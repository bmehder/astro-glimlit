## The smallest loop

The app holds a count in its model. A button sends a message, the update function produces the next model, and the view renders it.

```gleam
case msg {
  UserClickedIncrement -> #(Model(count: model.count + 1), [])
  UserClickedDecrement -> #(Model(count: model.count - 1), [])
  UserClickedReset -> #(Model(count: 0), [])
}
```

The empty list means there are no effects to run. For this counter, updating the model is all the work needed.

## The page and the app

Astro renders the article at build time. The Glimlit integration imports the compiled app and calls `main(root)` when Astro starts the island. The app renders only inside its mount element.

The counter appears exactly where its component is placed in this MDX file.
